# 几猫国产3A大作 · 局域网联机版

> **本项目全部代码（服务器、联机模块、协议、文档）基于 `mimo-v2.6-flash` 完成。**
>
> **声明：本项目纯粹出于个人爱好，仅限学习与研究使用，不得用于任何盈利目的；如涉及侵权问题，联系后立即删除。**

单机版 Three.js 第一人称射击（单文件 HTML）改造为**局域网多人联机**：玩家输入服务器地址进入，任意人数（≤16）混战，保留原 PvE 任务（切三处中继→撤离）与 AI 敌人，双方可互相攻击。

## 快速开始

```bash
# 服务器（零依赖，Python 3.12+ 标准库）
python3 server.py                # 默认 8080 端口
python3 server.py --port 18080   # 指定端口
python3 server.py --selftest     # 协议全链路自测（输出 SELFTEST PASS）
```

启动后终端会打印局域网地址，把 `http://IP:端口` 发给对手：

1. 双方浏览器打开地址 → 标题页出现「联机对战」面板
2. 填**服务器地址**（页面由本服务器打开时已自动填好）和**昵称**（≤12 字，自动记住）
3. 点「连接」→ **谁先连上谁开局**（可先单人打 AI），其他人随时加入
4. 不点连接直接进 = 原版单机，完全不受影响

> 同一局域网内也可直接用内网 IP（如 `http://192.168.1.100:18080`），不依赖端口转发。
> 校园网/外网访问需路由器端口转发到本机（WAN:端口 → 本机IP:同端口）；WAN IP 为 DHCP 时换 IP 后需更新转发目标。

## 改动清单（相对原单机版）

### 1. 联机服务器 `server.py`（新增，零依赖）
- 单端口同时提供 HTTP（游戏页）与 WebSocket（联机中继）
- 房间模型：字典按 id 索引，id 单调递增不复用，**上限 16 人**，满员发 `full`
- 20Hz 按接收者定制批量广播玩家状态；重生计时、击杀计分、断线清理均在锁内
- 启动打印局域网 IP；`--selftest` 内置三玩家协议全流程自测（含定向命中隔离、晚加入补进度、满员拒绝）
- 修复：未知路径返回真 404；非 dict JSON 消息丢弃；断线后单人仍可正常重生；槽位释放重置开局状态

### 2. 联机协议 v2（JSON over WebSocket）
- 客户端→服务器：`hello{name}` / `state{p,ya,pi,hp}`(50ms) / `hit{to,dmg}` / `dead{by}` / `relay{id}` / `extract`
- 服务器→客户端：`welcome{you,players,relays}` / `begin{players}` / `states{you,players,score}`(20Hz) / `hit{from,to,dmg}` / `dead{who,by,score,pos}` / `respawn{who,pos}` / `relay{id,from}` / `extract{from}` / `leave{who}` / `full`
- 伤害由攻击方上报（局域网互信）；服务器权威：击杀计分、重生计时、任务事件广播、中继进度记录（供晚加入者重放）

### 3. 客户端联机模块（HTML 末尾追加，不改原游戏逻辑）
- 「联机对战」面板：服务器地址 + 昵称输入（localStorage 记忆）、连接状态提示
- **远端玩家形象**：方块小人（头+面罩+橙色躯干+四肢），头顶动态名牌（名字+血条，随相机投影）
- 射击命中：`combat.playerShot` 包裹，射线 vs 胶囊体判定全部远端玩家取最近者，含墙/敌人遮挡检查（无副作用路径跳过原函数，避免一发子弹双重结算）
- 受击/死亡/5 秒重生（重生遮罩倒计时，屏蔽单机死亡屏的重试按钮）
- 任务同步：切断中继、到达撤离点经服务器广播，`applyingRemote` 标志防回声；晚加入者由 `welcome.relays` 补齐进度
- 击杀播报（带名字）、按击杀数排序的多人计分板
- 断线提示「对手已离开」，本地部分继续可玩

### 4. 游戏内部入口（原代码单点拼接，3 处方法）
- `game.cutRelayById(id)` / `game.finish()` / `game.respawn(pos)` —— 供联机模块调用；`respawn` 不走任务重置，保留已切中继进度

### 5. 弹药修复
- 根因：原版一条命 180 发（弹匣30+备弹150），备弹 `addAmmo` 无任何调用点；联机重生只重置血量 → 备弹打光后 `reserve<=0` 拒绝换弹
- 修复：`game.respawn` 内 `weapon.reset()` + `addAmmo(1e6)`；开局（begin）备弹拉满 → 永不缺弹（仅联机路径，单机平衡不变）

### 6. 难度调整（单机/联机一致）
| 项 | 原 | 现 |
|---|---|---|
| 开局巡逻 | 飞鸥2+猎犬1 | 飞鸥4+猎犬3 |
| 中继波次 | 3/1→3/2→4/3 | 5/3→6/4→7/5 |
| 同屏上限 | 9 | 16（掉帧可调小 `maxAlive`） |
| 刷怪间隔 | 0.85s | 0.55s |
| 追击增援 | 每7s、+5只 | 每5s、+8只 |
| 飞鸥射弹/自爆 | 7×3 / 30 | 12×3 / 45 |
| 猎犬射弹/扑咬 | 5×4 / 15(3.5s) | 9×4 / 25(2.5s) |

### 7. 其他
- HTTP 服务改为**每次请求重读 HTML**（改页面即时生效，改 `server.py` 才需重启）

## 已知天花板（刻意简化）

- 无断线重连续传：中途掉线需刷新页面重连；重连=新玩家重新开局（任务进度由中继重放补齐）
- 伤害判定为攻击方上报（局域网互信），无服务器射线校验/延迟补偿
- AI 敌人各自本地模拟，只在玩家间交互与任务事件走网络
- 联机命中不计入结算精度统计；对局中断线需刷新才能重开面板
- 满员上限 `MAX_PLAYERS=16` 一处可改
